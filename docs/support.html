💬 客服

智能客服、工单辅助与 FAQ 自动化。上线前务必做人机交接与幻觉防护，敏感操作需人工确认。

Intercom Fin

起步价：按 Intercom 套餐与解析量计费

一句话定位：面向产品内聊天与帮助中心的 AI 客服代理。

适合

SaaS / App 已用 Intercom 的团队；希望 AI 先答、复杂单转人工。

不适合

预算极紧的早期团队，或客服栈完全不在 Intercom 生态。

官网

Zendesk AI

起步价：随 Zendesk 套餐加购

一句话定位：工单系统内的智能回复、分类与助手能力。

适合

已有 Zendesk 工单流的中大型客服团队；邮件/多渠道工单为主。

不适合

只有简单网页聊天、没有工单体系的个人卖家。

官网

ChatGPT（自定义 GPT / API）

起步价：有免费档 · Plus / API 按用量

一句话定位：用知识库 + 提示词搭建轻量 FAQ 助手，灵活但需自己接渠道。

适合

内部试用、小型店铺 FAQ、原型验证；开发者用 API 嵌入自有站点。

不适合

需要开箱即用的多渠道工单、SLA 报表与座席权限体系时（应选专用客服平台）。
