Disclosure

How this directory handles affiliate links and sponsorship · Updated: 2026-11-10

CueAI is an independent directory of AI tools by use case, operated by Duo Qian under the ztlab name at www.ztlab.art. This page says when the site can earn money. It does not change which tools are listed or the order you see them in.

Affiliate links are marked

Some outbound links are affiliate links. Those links are marked: the page says so, and the link uses rel="sponsored". If you sign up or buy through a marked affiliate link, CueAI may earn a commission. That does not add a charge on your side, and it is not why a tool is on the list.

The office pages recommend Gamma when the job is a prompt-to-deck draft. That is an affiliate link. Other tool buttons on the site still use an ordinary referral parameter where no separate affiliate program is in use. We do not publish a commission rate.

Sponsorship is not ranking

Sponsorship is optional support for running the site. Paying to support CueAI does not move a tool up a scenario page, does not buy a badge that changes the order, and is not required to be listed. Browsing stays free.

If you want to support the site, use sponsor.html only.

Listing review

Asking for a tool to be reviewed is free. Paid placement is not open yet. Use List your tool and the same contact address as the footer: qddceo@mail.grokbot.com.
