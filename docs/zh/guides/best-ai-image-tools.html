怎么选图像 AI

「哪个图像 AI 最好」取决于交付物：氛围板、写文字时顺手出的插图、游戏素材，还是必须进现有设计软件的文件。版权和商用条款是选型的一部分。

先定这几件事

  • 观感还是可控。探索风格、保持艺术感，和像素级排版、嵌入品牌字体、海报必须对齐网格，不是同一件事。
  • 你怎么改。有的工具在 Discord 或网页里一轮轮改提示词，有的就在你写文字的对话里出图，有的则把很多模型和参数摊开。
  • 文件下一步去哪。团队已经在 Photoshop 或 Express 里做设计，就在同一套软件里生成，少一次导出。
  • 授权。客户稿发出去之前，读厂商当前的商用条款。这篇指南不代替你没读过的许可。
  • 产量。几张草稿不是工业化批量管线，托管产品也不是本地微调的开源模型。

下面的起步价与图像目录一致。有的厂商公布的是额度或套餐名，而不是一个公开月费，所以那些卡片保持定性描述。

Midjourney

起步价：订阅制（无长期免费档）

一句话定位：以艺术感与风格一致性见长的文生图工具（Discord / Web）。

适合

概念图、品牌氛围图、插画探索；愿意在 Discord 或 Web 里迭代提示词。

不适合

需要像素级可控排版、严格品牌字体嵌入，或完全离线本地部署。

官网

ChatGPT（图像）

起步价：随 ChatGPT 套餐（免费档能力有限）

一句话定位：对话式出图与改图，适合「一边说需求一边出图」的轻量流程。

适合

快速草稿、图标/插图试错、结合文字任务一起完成。

不适合

大批量工业化出图管线、或强依赖开源模型本地微调的团队。

官网

Leonardo.Ai

起步价：有免费额度 · 付费按月

一句话定位：偏游戏/资产向的文生图平台，模型与工作流选择较多。

适合

角色、道具、贴图类素材；想试用多种模型又不想自建环境。

不适合

只要极简「一句话出一张海报」、且不愿学习多参数面板的用户。

官网

Adobe Firefly

起步价：有免费额度 · 随 Creative Cloud 套餐

一句话定位：嵌入 Adobe 生态的生成式图像，面向设计稿与商用合规需求。

适合

已在用 Photoshop / Express 的设计师；关注训练数据与商用条款的团队。

不适合

完全不想碰 Adobe 账号体系、或追求最「网感」二次元画风的用户。

官网

可以这样缩小范围

  • 概念图和氛围板，并且愿意改提示词：Midjourney。目录卡片写的是订阅制，没有长期免费档。
  • 写文字时顺手要一张草稿：用 ChatGPT 图像，定稿再放进设计工具。
  • 角色、道具、贴图，又想试多种模型、不想自己托管：Leonardo.Ai。
  • 文件必须进 Photoshop 或 Express，而且授权是需求的一部分：Adobe Firefly，当前商用条款自己再核对一次。
