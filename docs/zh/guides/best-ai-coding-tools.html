怎么选编程 AI

有用的分界不是「哪个模型更聪明」，而是代码待在哪里：你现在的 IDE 里、一个以 AI 为中心的编辑器里，还是一个需要粘贴进去的对话窗口。

先定这几件事

  • 留在现有编辑器。团队已经用 VS Code 或 JetBrains，只想要补全、测试和解释时，IDE 助手改动更小。
  • 改整个仓库。要一边聊一边动很多文件，这是另一类产品，和行内补全不是一回事。
  • 方案还是按键。架构讨论、大段重构思路、文档和代码对照，适合上下文更长的对话。这种对话本身替代不了行内补全。
  • 代码能不能出域。隔离网络，或仓库默认不能离开本机，要先看企业合规方案。免费档回答不了这条约束。
  • 审查。生成的代码当草稿。合入生产前看 diff，和看同事的改动一样。

下面的起步价与编程目录一致。官方只写「Pro 按月」或优惠计划、没有公开单一月费时，这里不补一个数字。

GitHub Copilot

起步价：Individual 约 $10/月 · 有学生/开源优惠

一句话定位：在常用 IDE 里做行内补全与聊天式改代码。

适合

VS Code / JetBrains 用户；日常补全、写测试、解释陌生代码。

不适合

完全禁止云端代码外传的受限环境（需确认企业合规方案）。

官网

Cursor

起步价：有免费档 · Pro 订阅按月

一句话定位：以 AI 为中心的代码编辑器，擅长多文件理解与项目级改动。

适合

希望「在整个仓库里聊着改」的个人开发者与小团队。

不适合

必须锁定公司统一 IDE 插件策略、且无法更换编辑器的场景。

官网

Claude

起步价：有免费档 · Pro 约 $20/月

一句话定位：强于读长代码、写方案与分步实现，可配合 Artifacts / 项目空间使用。

适合

架构讨论、大段重构思路、文档与代码对照阅读。

不适合

需要深度嵌进本地 IDE 行内补全且不想切换窗口的工作流（可另配扩展）。

官网

ChatGPT

起步价：有免费档 · Plus 约 $20/月

一句话定位：通用编程问答与小段代码生成，生态广、上手成本低。

适合

学新 API、写脚本、排查报错思路；配合 Canvas/自定义 GPT。

不适合

对仓库全貌持续索引、或企业私有代码默认不出域的硬性要求（需企业版评估）。

官网

可以这样缩小范围

  • 编辑器不动，只要边写边补全：GitHub Copilot。
  • 可以换编辑器，而且改动跨很多文件：Cursor。
  • 先要一份方案，或先把一大段改动读清楚：用 Claude，再回到你信任的编辑器里落地。
  • 在学一个 API，或只是排查一小段脚本：ChatGPT 足够起步。代码要留在项目里时，再换 IDE 工具。
